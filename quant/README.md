# Trend-Parity — Quant Research

Research directory for the **Trend-Parity** momentum strategy — a 3-asset
ETF portfolio that beats QQQ's 1999-2026 CAGR (11.98 % vs 10.37 %) while
cutting the worst drawdown by 4× (−20.5 % vs −83 %).

See **`strategy_report.md`** for the full write-up, metrics, sensitivity
analysis and honest verdict against the target specification.

## Quickstart

```bash
# Install (venv recommended)
pip install yfinance pandas numpy matplotlib scipy

cd quant/

# 1) Download the CSV cache (~14 MB)
python3 download_data.py

# 2) Run the backtest
python3 strategy.py

# 3) Full robustness / walk-forward
python3 robustness.py

# 4) Render equity + drawdown + allocation chart
python3 make_chart.py

# 5) Generate today's target allocation
python3 live_signals.py --capital 100000
```

## Files

| File                 | Role                                                   |
| -------------------- | ------------------------------------------------------ |
| `framework.py`       | Data loader, vectorised backtest engine, metrics       |
| `strategy.py`        | Final strategy + `run_backtest_strategy()` entry point |
| `live_signals.py`    | Production daily position generator                    |
| `make_chart.py`      | Equity / drawdown / allocation visualisation           |
| `robustness.py`      | Parameter sensitivity, walk-forward, cost stress       |
| `download_data.py`   | yfinance bulk download (idempotent)                    |
| `explore*.py`        | Research notebooks from the 300+ config grid search    |
| `strategy_report.md` | Full report                                            |
| `backtest_chart.png` | Generated by `make_chart.py`                           |
| `data/*.csv`         | Cached prices (git-ignored)                            |
